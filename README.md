# Portafolio Web GIS — José Christos García

Portafolio profesional centrado en la creación rápida de visores Web GIS para proyectos de drones, ortofotos, modelos, capas temáticas, infraestructura vial e indicadores territoriales.

## Publicación

El repositorio está preparado para publicarse automáticamente con GitHub Pages mediante GitHub Actions.

## Estructura

- `index.html`: contenido del portafolio.
- `styles.css`: diseño, tipografías, interacciones y adaptación móvil.
- `assets/`: imágenes, favicon, tarjeta social y fuentes locales.
- `.github/workflows/pages.yml`: despliegue automático en GitHub Pages.

## Actualización

Los cambios enviados a la rama `main` generan una nueva publicación. El sitio no requiere base de datos ni servidor de aplicaciones.

## Uso de evidencias

Las imágenes y enlaces corresponden a referencias visuales de proyectos públicos. No se incluyen credenciales, configuraciones internas, bases de datos ni procedimientos operativos sensibles.
